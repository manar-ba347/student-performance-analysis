# Student Performance Analysis 📊

**Course:** AI3301 - Data Analysis & Visualization
**Dataset:** Student Performance (provided by Prof. Omniah H. Nagoor)

## Project Overview
This project analyzes the relationship between students' average score
and demographic and test preparation factors, to find out whether these
factors influence academic performance.

## Hypotheses
- **H1:** Does the test preparation course affect the average score?
- **H2:** Does the parents' level of education influence students' grades?
- **H3:** How strongly does race/ethnicity play a role in the average score?

## Work Done
- Explored the dataset (shape, data types, summary statistics)
- Cleaned invalid score values (-99 / -10) and handled missing values
- Standardized the `test preparation course` column
- Filled missing scores with the median and missing `lunch` values with the mode
